# CHRSF — ЧРСФ-фильтр

Разработка и исследование алгоритма четырёхкаскадного рекурсивно-сепарабельного фильтра (ЧРСФ) с возможностью формирования многоэлементной неравносторонней апертуры с адаптивной корректирующей маской.

## Состав проекта

### Исходный код

- `crsf_fast.py` — ускоренная реализация ЧРСФ: параметры маски, рециркуляторы, фильтрация, расчёт апертуры, пересчёт коэффициентов `A1/A2` и `k/w`.
- `rsf_filter.py` — исходная (опорная) реализация фильтра, используется в задаче 10 для проверки корректности.
- `quality.py` — метрики качества: MTF/MTF50, ТВЛ, ОСШ (SNR), СКО, PSNR, SSIM, выброс/ореол, свойства маски.
- `test_images.py` — генерация/загрузка тестовых изображений: мира `640x480` и Lena `512x512` (эталон, размытие, шум).
- `experiment.py` — прогон обработки и расчёт показателей для заданного окна и коэффициентов.

### Задачи

- `task10_optimization.py` — **Задача 10**: проверка корректности ускоренного фильтра, сравнение числа операций и времени работы (КДС, исходный ЧРСФ, ускоренный ЧРСФ).
- `task11_coefficients.py` — **Задача 11**: влияние коэффициентов `A1`, `A2`, `k`, `w` на качество обработки для окон `7x7`, `7x3`, `3x7`, `11x5`.
- `task12_aperture.py` — **Задача 12**: влияние размеров/формы апертуры на качество; режим A (`A1,A2` постоянны) и режим B (`k,w` постоянны).

### Вспомогательные скрипты

- `make_figures.py` — формирование отдельных рисунков для отчёта в `results/fig/`.
- `filter_figures.py` — дополнительные рисунки по фильтру.
- `build_report.py` — сборка материалов отчёта.

### Данные и результаты

- `test_images/` — тестовые изображения (`chart/lena`, эталон и вход).
- `results/` — результаты расчётов: CSV-таблицы, логи, PNG-графики и рисунки (`results/fig/`).

## Зависимости

Python 3.x и библиотеки:

```bash
pip install numpy pillow matplotlib
```

## Запуск

Запускать из каталога проекта:

```bash
python test_images.py          # сгенерировать/проверить тестовые изображения
python task10_optimization.py  # задача 10
python task11_coefficients.py  # задача 11
python task12_aperture.py      # задача 12 (использует results/task11_optimum.csv)
python make_figures.py         # рисунки для отчёта
```

## Примечания

- `task10_optimization.py` и `test_images.py` в текущем виде ожидают файл `lena.png` в каталоге на уровень выше проекта (`../lena.png`). Это внешняя зависимость, путь в коде намеренно не изменялся.
- `task10_optimization.py` сравнивает ускоренную реализацию с исходной `rsf_filter.py`; файл `rsf_filter.py` включён в репозиторий.
- Результаты экспериментов сохраняются в каталог `results/`.
